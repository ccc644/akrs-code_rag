# 源码大目录

本目录用于集中放置被分析的多个 Python 项目，每个子目录是一个独立项目：

| 子目录 | 项目 | 说明 |
| --- | --- | --- |
| `swe-agent/` | SWE-agent | NeurIPS 2024（CCF-A）软件工程 Agent，默认项目指向这里 |
| `sglang/` | SGLang（待放入） | NeurIPS 2024（CCF-A）LLM 推理服务框架 |

新增项目时，把仓库克隆到本目录下（例如 `trunk/sglang`），再在应用里新建项目并将「主源码目录」指向对应子目录。不要把多个仓库直接放在 `trunk` 根目录，否则会被当成同一个代码库。

上游说明见 `UPSTREAM.md`；源码保持只读，应用不会修改或执行这些业务项目。
